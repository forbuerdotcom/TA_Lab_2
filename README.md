# Калькулятор отделочных материалов (Вариант №10)

## Описание
MVP-приложение с графическим интерфейсом (Tkinter) для расчета количества и итоговой стоимости отделочных материалов (обоев, плитки, ламината) в зависимости от площади помещения. Программа реализована с использованием ООП, поддерживает валидацию ввода и позволяет сохранять результаты расчетов в документ формата Microsoft Word (.docx).

## Инструкции по запуску
1. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
2. Запустите основной файл программы:
   ```bash
   python main.py 
   
Краткая справка

1. Введите площадь помещения в квадратных метрах (кв.м).

2. Выберите тип материала из выпадающего списка (Обои, Плитка, Ламинат).

3. Введите цену за одну единицу материала (за рулон или за кв.м).

4. Нажмите кнопку «РАССЧИТАТЬ», чтобы увидеть количество и итоговую стоимость в правой части окна.

5. Нажмите кнопку «СОХРАНИТЬ ОТЧЕТ», чтобы выгрузить результат в файл Word.

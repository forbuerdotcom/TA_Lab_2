# Калькулятор отделочных материалов (Вариант №10)

## Описание
MVP-приложение с графическим интерфейсом (Tkinter) для расчета количества и итоговой стоимости отделочных материалов (обоев, плитки, ламината) в зависимости от площади помещения. 

Проект реализован с использованием объектно-ориентированного программирования (ООП), модульной структуры и абстрактных базовых классов. Программа поддерживает валидацию ввода, сохраняет историю расчетов в базу данных SQLite3 и позволяет экспортировать результаты в документ формата Microsoft Word (.docx).

## Инструкции по запуску
1. Убедитесь, что у вас установлен Python 3.8+.
2. Клонируйте репозиторий или скачайте файлы проекта.
3. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
4. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
5. Запустите основной файл программы:
   ```bash
   python main.py
# Краткая справка (Как пользоваться)

1. Введите площадь помещения в квадратных метрах (кв.м). Значение должно быть больше 0.

2. Выберите тип материала из выпадающего списка (Обои, Плитка, Ламинат).

3. Введите цену за одну единицу материала (за рулон для обоев или за кв.м для плитки/ламината). Цена не может быть отрицательной.

4. Нажмите кнопку «РАССЧИТАТЬ». В правой части окна появится количество материала с учетом запаса и итоговая стоимость.

5. Нажмите кнопку «СОХРАНИТЬ ОТЧЕТ», чтобы выгрузить результат в файл Word (.docx).

# Проект разделен на пакет и основной исполняемый файл:

    main.py — основной файл с графическим интерфейсом (Tkinter).

    materials_package/ — пакет с бизнес-логикой:

        __init__.py — инициализация пакета.

        models.py — классы материалов (ООП, наследование).

        reporter.py — модуль для сохранения отчета в Word.

        database.py — модуль для работы с БД SQLite3.

    test_modules.py — файл с тестами (pytest).

    requirements.txt — список зависимостей.
